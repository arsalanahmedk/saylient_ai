# Web app — placeholder (Phase 4)

This folder is intentionally empty in Phase 0–2.

The web app (React + TypeScript, dashboard / compose / history / settings)
is built in **Phase 4** of the plan (`docs/ROADMAP.md`), after the API
baseline and the dataset are in place. When it is built, its design will
take inspiration from high-quality reference sites — layout, spacing,
typography and interaction patterns — without copying any site's
copyrighted assets, images, text, or code.

Do not build a generic placeholder frontend here: a rushed generic UI
would set the wrong design bar for the whole project. See
`docs/UI_UX_SPEC.md` for the screens and design tokens.
